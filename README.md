# \# Dynamic Trees for Better Nether

# 

# Bring Dynamic Trees support to the trees and giant fungi added by BetterNether.

# 

# This addon integrates BetterNether's vegetation with Dynamic Trees, allowing

# supported species to grow, branch, and generate using Dynamic Trees' mechanics

# while preserving their distinctive shapes and behavior.

# 

# \## Features

# 

# 🌳 \*\*Dynamic Trees compatibility for BetterNether\*\* – Adds dynamically growing

# versions of supported BetterNether tree species.

# 

# 🌿 \*\*Custom growth and world generation\*\* – Preserves each species'

# characteristic height, canopy, branching, biome placement, and natural growth

# behavior.

# 

# 🍄 \*\*Dynamic giant fungi support\*\* – BetterNether's giant fungi grow and generate

# dynamically through Dynamic Trees Plus while retaining their unique appearance.

# 

# ⚡ \*\*Lightweight compatibility addon\*\* – Integrates seamlessly with BetterNether

# and Dynamic Trees while remaining lightweight and easy to install.

# 

# \## Requirements

# 

# \- Dynamic Trees

# \- BetterNether NeoForge

# \- Dynamic Trees Plus
